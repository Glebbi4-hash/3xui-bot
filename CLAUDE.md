# CLAUDE.md — 3xui-bot (@GlebbIbot)

Telegram-бот для управления панелью 3x-ui v3.x: онбординг клиентов, подписки, мониторинг трафика, админ-сценарии. Закрытый круг пользователей («для своих»), но осторожность с данными и доступами обязательна.

## Окружение

- Python, aiogram 3, apscheduler 3.10.4 (`AsyncIOScheduler`)
- Сервер: Ubuntu 24, `vgs.glebbi4.ru` (hostname PRX), путь `/opt/3xui-bot/`, systemd-сервис
- Репозиторий: `github.com/Glebbi4-hash/3xui-bot`
- Тестовый пользователь (не админ): Telegram ID `8854468313` — для проверки пользовательских сценариев
- Секреты — только в `.env`, никогда не коммитить и не выводить значения в логи/ответы

## Панель 3x-ui: авторизация и API

- Только Bearer-токен: `config.API_TOKEN` (из `.env`, ключ `API_TOKEN`), передаётся 4-м аргументом в `XUIClient`
- Логин по паролю НЕ использовать — ненадёжен; standalone-скрипты вне systemd с ним падают
- Эндпоинты:
  - добавить клиента: `/panel/api/clients/add`
  - удалить: `/panel/api/clients/del/{email}`
  - обновить: `/panel/api/clients/update/{email}`
  - сбросить трафик: `/panel/api/clients/resetTraffic/{email}`
  - перезапуск Xray: `/panel/api/server/restartXrayService`
- URL подписки: `https://vgs.glebbi4.ru:2096/xQ7vLm3pR/{subId}`
- Сеть: для Telegram API нужен SOCKS-прокси `127.0.0.1:10808`; для API панели — не нужен

## Текущее состояние

- Основные сценарии готовы, идёт итеративная доработка
- Мониторинг: три статуса клиента с легендой — 🟢 онлайн (<3 мин) / 🔴 офлайн / ⚫ отключён
- Уведомления об истечении: `tasks.py`, cron 18:00 Europe/Moscow, за 1 и 3 дня, инлайн-кнопка «⏳ Продлить»
- Кнопка «🏠 Главное меню» на QR-фото → callback `user:menu`, отправляет новое сообщение

## Правила реализации (выстраданные)

- Фото-сообщения нельзя `edit_text` — всегда отправлять новое сообщение
- Продление — через `update_client` с сохранением UUID и `subId`
- «Мои активные подписки» фильтруются по наличию `subId`, а не по сырым клиентам
- Все кнопки возврата — строго «◀️ Назад»
- Карточка клиента: inbound, Telegram username (через `bot.get_chat(tgId)`), last online, дата создания (`created_at` в мс ÷ 1000), лимит устройств, трафик, срок в формате `Истекает: DD.MM.YYYY (через N дн.)`
- Reply Keyboard на iOS (нужен ☰) — известное ограничение платформы, оставлено как есть осознанно

## Git-дисциплина

- После каждого `git push` обновить README.md под новые/изменённые фичи, закоммитить и запушить
- Remote: `git@github.com:Glebbi4-hash/3xui-bot.git` (deploy key `~/.ssh/3xui_deploy`, только этот репо). Никогда не вписывать токены в URL remote
- Работа идёт под пользователем `vpnadmin`; сервис `3xui-bot.service` запущен от root
- После изменений кода — перезапуск сервиса и проверка логов (каждый restart подтверждает владелец):
  - `sudo systemctl restart 3xui-bot.service`
  - `sudo journalctl -u 3xui-bot.service -n 50 --no-pager`
- `.env` не читать и не выводить (запрещено в `.claude/settings.json`)
- Исходящий трафик Claude Code к Anthropic идёт через Xray `mixed` inbound `127.0.0.1:10808` (выход EE)
